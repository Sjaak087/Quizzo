Quizzo v35 patch — quizbeschrijving + sitebeheer voor alle quizzen

Vervang app.js en style.css in je bestaande repo. Laat index.html, firebase.js, theme-assets.js en themes/ staan.

Nieuw:
- Quiz instellingen hebben nu een blijvende beschrijving.
- Beschrijving wordt opgeslagen bij de quiz en zichtbaar in Ontdek quizzen + openbare quiz-preview.
- Sitebeheer toont alle quizzen van alle gebruikers.
- Sitebeheer kan iedere quiz bewerken: titel, beschrijving, thema, openbaar/privé, alle vragen, vraagvolgorde, punteninstellingen en vraagtypes.
- Sitebeheer kan quizzen ook verwijderen.
- Admin-bewerkingen worden opgeslagen onder de oorspronkelijke eigenaar, zodat de quiz bij dezelfde gebruiker blijft horen.
- Geen themes-bestanden inbegrepen.
